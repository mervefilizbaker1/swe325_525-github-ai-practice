## Core Concepts
* **Issues:** Used to define tasks, acceptance criteria, and track progress before implementing changes.
* **Branches:** Isolated working environments (like `feature/github-ai-workflow`) used to develop changes without affecting the default branch.
* **Commits:** Meaningful snapshots of changes with descriptive messages (e.g., avoiding vague terms like "update").
* **Pull Requests (PR):** Mechanisms to review changes, link issues, discuss code, and merge features back into the default branch.
